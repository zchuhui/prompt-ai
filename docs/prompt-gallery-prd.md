# Prompt Gallery 产品需求文档

**版本：V1.0 · MVP**  
**日期：2026-10-26**  
**产品定位：面向公众开放的图片生成 Prompt 灵感库。**  
**项目名称：Prompt Gallery（暂定）**

## 1. 产品目标

将自己整理、创作和收集的图片生成提示词，以高质量图片为入口对外展示，帮助访客快速发现灵感、理解生成条件并复制使用，同时通过搜索引擎和内容分享获取流量。

核心体验：

> 浏览效果图 → 找到感兴趣的内容 → 查看图片与 Prompt → 复制使用或分享。

管理体验：

> 上传图片 → 填写 Prompt → 整理分类与模型 → 预览 → 发布。

第一版重点做好 **图片展示、内容发现、提示词复制和后台录入**。

## 2. 用户与权限

| 角色 | 权限 |
|---|---|
| 访客 | 浏览已发布内容、搜索筛选、查看大图、复制 Prompt、分享链接 |
| 管理员 | 登录后台，管理内容、图片、分类、标签、模型和合集 |

访客无需注册或登录。后台使用独立管理员认证；所有新增、修改、删除和上传接口都必须校验权限。

## 3. 信息架构

```text
公开页面
首页 / 图片库
Prompt 详情页
专题合集列表
专题合集详情
关于与来源说明

管理后台
登录
内容列表
新建 / 编辑内容
批量上传
分类 / 标签 / 模型管理
合集管理
```

## 4. 前台需求

### 4.1 首页 / 图片库

**目标：让图片成为视觉中心，帮助用户快速发现感兴趣的 Prompt。**

页面从上到下包括：

- 顶部导航：品牌名称、图片库、专题合集、搜索入口。
- 简洁介绍区：一句产品介绍，避免大幅宣传区占用图片空间。
- 分类与筛选区：分类、模型、标签。
- 图片瀑布流：展示已发布内容。
- 底部：关于、来源说明等信息。

**卡片内容**

- 封面图片。
- 内容标题。
- 模型名称。
- 多图数量角标，例如“4 张”。
- 悬停或点击反馈。

**交互规则**

- 点击卡片进入独立详情页。
- 图片保持自然比例，设置合理的展示高度上限。
- 预留图片空间，减少加载时布局跳动。
- 返回列表时，保留搜索条件与浏览位置。
- 默认按发布时间倒序排列。
- 采用分页加载，提供明确的“加载更多”入口。

### 4.2 搜索与筛选

| 功能 | 规则 |
|---|---|
| 关键词搜索 | 搜索标题、简介、Prompt 正文和标签 |
| 分类筛选 | 单选，默认全部 |
| 模型筛选 | 单选，默认全部 |
| 标签筛选 | 支持多选，匹配任意已选标签 |
| 组合筛选 | 关键词、分类、模型、标签条件之间取交集 |
| 清空筛选 | 一键恢复默认状态 |
| 状态保留 | 搜索和筛选条件写入 URL，刷新和分享后可还原 |

无结果时显示当前条件，并提供“清空筛选”操作，不留下空白页面。

### 4.3 Prompt 详情页

**电脑端：** 图片与内容采用双栏布局，长提示词有足够阅读空间。  
**手机端：** 先展示图片，再展示标题、模型与提示词，复制按钮容易触达。

| 模块 | 内容 |
|---|---|
| 图片展示 | 多图切换、缩略图、点击查看大图 |
| 基本信息 | 标题、简介、分类、标签 |
| 生成信息 | 模型、可选模型版本、图片比例、其他参数 |
| 主提示词 | 保留换行，支持一键复制 |
| 负面提示词 | 有内容时显示，单独复制 |
| 使用说明 | 可选，说明参考图、替换变量或操作方法 |
| 来源信息 | 原创 / 收集、作者、来源链接 |
| 相关推荐 | 优先推荐同分类或有共同标签的内容 |

**内容约定**

- 一条内容对应一份主 Prompt，可以展示多张效果图。
- 多张图应当属于同一 Prompt 和同一模型配置下的效果示例。
- 不同 Prompt 或不同模型的对比，拆为多条内容，通过合集关联。
- 需要参考图的 Prompt 应有明确标记，避免访客误以为只复制文字即可复现。

**复制与分享**

- 主按钮复制纯 Prompt 文本，保留换行。
- 参数和负面提示词分别复制。
- 复制成功显示明确提示，失败时提供手动选取方式。
- 分享按钮复制当前详情页链接。
- 显示简短说明：生成效果可能因模型版本、参数与随机性不同而变化。

### 4.4 专题合集

用于组织系列内容，例如：

- 治愈系植物壁纸。
- 东方神话海报。
- 写实人像摄影。
- 3D 角色设定。

合集包含标题、简介、封面和多条已发布内容。管理员可手动调整内容顺序；同一条内容可以属于多个合集。

## 5. 后台需求

### 5.1 内容列表

展示封面、标题、模型、分类、状态和更新时间。

支持：

- 按标题搜索。
- 按发布状态、分类和模型筛选。
- 编辑、预览、复制为草稿。
- 发布、撤回为草稿、删除。
- 批量发布、撤回和删除。

删除需要二次确认；批量操作明确显示涉及的内容数量。

### 5.2 单条录入与编辑

建议录入顺序：

1. 上传一张或多张效果图。
2. 选择封面、调整图片顺序。
3. 填写标题和主 Prompt。
4. 选择模型、分类、标签。
5. 按需填写参数、使用说明和来源。
6. 保存草稿或预览发布。

**易用性要求**

- 电脑支持拖拽上传、文件多选和粘贴剪贴板图片。
- 手机支持从相册多选上传。
- 每张图片显示上传进度、成功或失败状态。
- 上传失败可单独重试，不清空已填写内容。
- 图片可排序、替换、删除和设为封面。
- 发布按钮防止重复提交。
- 有未保存修改时，离开页面给予提醒。
- 手机端保存与预览操作保持容易触达。

### 5.3 批量上传

上传前提供两种模式，避免图片归属混乱：

| 模式 | 行为 |
|---|---|
| 多张图片创建一条内容 | 整组共用一份 Prompt，选择一张封面 |
| 每张图片创建一条草稿 | 为每张图片建立独立草稿，后续分别补充 Prompt |

批量流程：

1. 选择上传模式与图片。
2. 展示上传队列。
3. 可统一设置模型、分类和标签。
4. 完成上传后生成草稿。
5. 逐条填写标题和 Prompt。
6. 校验后发布。

**发布校验：** 必须有标题、至少一张上传成功的图片、主 Prompt、模型和分类。批量发布时，仅发布满足条件的条目，并列出失败原因。

第一版不自动猜测图片对应的 Prompt，也不自动发布尚未检查的内容。

### 5.4 分类、标签与模型管理

- 分类：第一版采用一级分类，可调整顺序。
- 标签：支持新增、重命名、删除，防止重复名称。
- 模型：支持名称、可选版本说明、排序和停用。
- 已被内容引用的分类或模型，不允许直接删除；需先迁移关联内容。
- 删除标签仅移除标签关联，不删除内容。

### 5.5 发布状态

第一版保留两种状态：

| 状态 | 行为 |
|---|---|
| 草稿 | 仅管理员可查看，不出现在公开页面与站点地图 |
| 已发布 | 可以公开访问，进入列表、搜索和相关推荐 |

撤回发布后，公开详情页不再返回内容。管理员预览需验证登录状态。

## 6. 内容数据字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 标题 | 是 | 可读、可搜索的内容名称 |
| 独立链接标识 | 自动 | 保持稳定，修改标题不自动改变链接 |
| 简介 | 否 | 简短描述画面或用途 |
| 图片列表 | 是 | 图片地址、尺寸、排序、替代文字 |
| 封面图片 | 是 | 默认第一张，可修改 |
| 主 Prompt | 是 | 保留原始文本格式 |
| 负面 Prompt | 否 | 适用于支持该功能的模型 |
| 模型 | 是 | 从模型库选择 |
| 模型版本 | 否 | 记录生成时使用的版本 |
| 分类 | 是 | 一条内容对应一个主分类 |
| 标签 | 否 | 支持多个 |
| 图片比例 | 否 | 如 9:16、3:4、1:1 |
| 其他生成参数 | 否 | 文本形式保存，第一版不做复杂参数编辑器 |
| 需要参考图 | 是 | 默认否 |
| 使用说明 | 否 | 补充生成条件和操作方法 |
| 来源类型 | 是 | 原创 / 收集 |
| 作者与来源链接 | 否 | 收集内容建议填写 |
| 所属合集 | 否 | 支持多个 |
| 发布状态 | 是 | 草稿 / 已发布 |
| 创建、更新、发布时间 | 自动 | 支持排序与维护 |

草稿可以暂缺必填项，上述必填要求在发布时校验。

## 7. 视觉设计要求

整体采用 **深色、克制的科技感**（2026-10-27 由浅色杂志风调整，见 T10）：

- 背景：近黑底色，叠加极淡的点阵网格与顶部青紫渐变光晕，不抢图片。
- 正文：浅灰色，正文与背景对比达到 WCAG AA。
- 强调色：单一青色用于选中状态和主要操作；紫色只用于渐变点缀。
- 元信息：模型、比例、张数、字数等使用等宽字体，Prompt 正文以终端窗口样式呈现。
- 图片：作为页面视觉主体，减少装饰性元素。
- 卡片：1px 细边框，悬停时边框发光，不使用厚重阴影。
- 排版：清晰的标题层级，舒适的行距和留白。
- 动效：仅用于悬停、切换和状态反馈，尊重减少动态效果设置。

**响应式原则**

| 屏幕 | 展示方式 |
|---|---|
| 手机 | 图片列表默认两列，详情单列；筛选使用抽屉或弹层 |
| 平板 | 根据宽度展示两至三列 |
| 电脑 | 根据内容区域宽度展示三至五列，避免卡片过小 |

操作不依赖鼠标悬停；按钮支持键盘访问，图片查看器支持关闭和前后切换。

## 8. 性能、SEO 与统计

### 图片与性能

- 上传后生成适合卡片和详情页的不同尺寸图片。
- 列表使用缩略图，避免直接加载全部原图。
- 首屏图片优先加载，后续图片懒加载。
- 存储图片宽高信息，减少布局偏移。
- 预设第一版单图上限为 20 MB，单条最多 20 张，批次最多 100 张；在上传前显示限制。
- 第一版支持 JPG、PNG、WebP；不支持的格式给出明确提示。

### 搜索引擎与分享

- 公开详情页具有可索引的 HTML 内容。
- 各页面设置独立标题、描述、规范链接和分享预览图。
- 站点地图仅包含公开内容。
- 后台和草稿不参与索引。
- 无效、已删除或已撤回的公开地址返回合适的页面状态。
- 搜索与组合筛选页避免产生大量重复索引页面。

### 基础统计

记录页面访问、详情浏览、Prompt 复制、搜索和无结果搜索，用于判断：

- 哪些题材更受欢迎。
- 哪些 Prompt 更有使用价值。
- 用户在找什么尚未收录的内容。

统计不应保存管理员填写的未发布 Prompt 或认证信息。

## 9. 第一版不包含

- 访客注册与登录。
- 用户投稿、评论、点赞和云端收藏。
- 付费内容、会员和支付。
- 在线调用模型生成图片。
- 自动抓取第三方内容。
- AI 自动反推 Prompt。
- 多管理员角色与复杂权限。
- 多语言界面。

## 10. 验收标准

第一版完成时，应满足以下可验证条件：

1. 访客无需登录即可浏览、搜索和查看已发布内容。
2. 分类、标签、模型与关键词可以按约定组合筛选。
3. 每条内容拥有独立链接，刷新和直接访问均正常。
4. 多张效果图可切换和放大，手机操作正常。
5. Prompt 复制结果与保存文本一致，保留换行。
6. 管理员可在电脑和手机完成上传、编辑、预览及发布。
7. 两种批量上传模式能够生成正确的内容归属。
8. 上传失败可重试，其他成功图片与表单内容保留。
9. 必填内容不完整时无法发布，并明确指出缺少项。
10. 草稿不能通过公开页面、搜索或未认证接口读取。
11. 未登录用户无法调用管理和上传接口。
12. 删除、撤回和修改后，公开展示与搜索结果同步更新。
13. 页面没有明显横向溢出、图片变形或加载布局跳动。
14. 已发布详情具有正确的标题、描述和分享预览信息。

## 11. 开发顺序

先确定视觉样稿与数据结构，再打通“后台上传 → 发布 → 前台查看 → 复制 Prompt”的完整流程，最后补齐批量管理、专题合集和 SEO。
