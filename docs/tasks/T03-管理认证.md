## 认证边界

密码用 Argon2id，参数为 memoryCost 19456、timeCost 2、parallelism 1。脚本只从隐藏输入读密码。会话 token 为 32 字节，库里只存 SHA-256，绝对过期 8 小时。`APP_URL` 为 http 时 Cookie 名是 `pg-session`；生产 https 使用 `__Host-pg-session`。变更请求校验 Origin，并校验由会话 token 和 `CSRF_SECRET` 派生的 `X-CSRF-Token`。登录限流只读 `x-real-ip`，不读 `X-Forwarded-For`。

## 已知限制

页面跳转只负责把未登录用户带到登录页。接口各自调用 `requireAdmin` 或 `requireAdminMutation`。
