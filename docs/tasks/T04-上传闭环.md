## 验收命令与结果

`pnpm test:integration` 退出码 0。`tests/integration/upload.test.ts` 覆盖：

- `single` 共享一个草稿，`multiple` 每项一个草稿，追加到已有草稿。
- 相同 Idempotency-Key 与相同 body 返回原批次，不同 body 返回 409。
- 真 PNG 生成 original、card、detail，并保留私有 `source_key`。
- 假扩展名和 SVG 进入 failed，且不再被领取。
- 实际字节超过 20 MiB 返回 413。
- 存储读取失败后 10 秒可重试并最终 ready。
- 过期租约不能用旧 `lease_token` 完成，重复完成返回 false。
- 对象写入后数据库唯一约束失败时删除临时对象，上传条目保持 pending。

`tests/integration/migration.test.ts` 确认空库应用两条 migration，并且已有 `original_key` 的旧行能补上 `source_key`。

`pnpm exec tsup && node --check dist/worker/index.js` 通过。Worker 产物是 `dist/worker/index.js`，旁边有 `{"type":"module"}`，因此现有 `node dist/worker/index.js` 可以按 ESM 运行。

## 存储

默认 `STORAGE_DRIVER=s3`。集成测试和这次浏览器验收使用内存驱动，不连接 MinIO。内存驱动只在同一个进程里可见，生产仍应使用 S3 和独立 Worker。公开衍生图键为 `public/{assetId}/v1/{original,card,detail}.webp`，源文件留在 `tmp/` 或处理前的私有键。
