## 验收命令与结果

`tests/integration/gallery.test.ts` 通过。已发布内容能按标题、分类、模型和标签搜到。公开媒体返回图片且 `Cache-Control: no-store`。共享图片在仍有另一条公开内容时继续可访问；两条都撤回后媒体返回 404。

开发服务器上的浏览器操作：

- 首页只显示已发布的「治愈系植物壁纸」，不显示空草稿。
- 打开详情后，主 Prompt 文本为 `第一行提示词\n第二行提示词`。
- 复制按钮在剪贴板不可用时给出原文文本框，换行仍在。
- 点击图片打开大图，点击「关闭」后大图消失。
- 搜索不存在的词显示「没有符合当前条件的内容」。
- 撤回后刷新首页，卡片消失。旧媒体地址返回 404。
- 390、768、1440 宽度下首页或关于页 `scrollWidth` 不超过视口。

## 查询

列表排序为 `published_at DESC, id DESC`。`q` 在 ILIKE 前转义 `%`、`_` 和反斜杠。分类、模型和搜索是 AND，标签是 OR。
