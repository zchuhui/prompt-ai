## 验收命令与结果

`pnpm test:integration` 中的 `tests/integration/content.test.ts` 通过。没有图片时发布返回 422，过期 version 返回 409，撤回后公开搜索不再返回该内容。批量发布同时返回一条 422 和一条 409，删除批量可以一条成功、一条失败。复制生成新的 slug。

开发服务器上完成了一次真实流程：编辑种子草稿、上传 PNG、处理为 ready、发布返回 200、撤回返回 200。未登录调用这些写接口返回 401。

后台列表、编辑、预览、上传、分类和合集页面已接上。图片使用普通 `img`，不走 Next 图片优化。shadcn 风格的 Button 源码在 `src/components/ui/button.tsx`，站点标题使用 Lucide 的 `Images` 图标。

## 发布规则

发布在服务端事务里检查标题、主 Prompt、1 到 20 张 ready 图片、分类、模型和新发布时模型必须为 active。封面必须属于该条内容的图片。slug 在创建时生成，之后不改。批量动作逐条独立事务，最多 100 项。

## 已知限制

浏览器里没有走完后台表单的每一次点击。发布和撤回是通过已登录的 API 调用完成的，页面跳转不能代替这些接口的鉴权。
