## 部署约定

Web 与 Worker 使用同一个镜像。Dockerfile 复制 pnpm 的完整 `node_modules`，因为 sharp、argon2 和 pg 的传递依赖不会被提升到顶层。迁移由一次性 `pnpm db:migrate` 执行，不在 Web 进程启动时运行。Caddy 把请求体限制在 22 MB，用 `{remote_host}` 覆盖 `X-Real-IP`，并去掉入站 `X-Forwarded-For`。媒体响应强制 `Cache-Control: no-store`。
